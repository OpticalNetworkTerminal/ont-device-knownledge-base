# ont-device-knowledge-base

Linux ONT（光猫、家庭网关、ONU）知识库。

第一阶段目标是完成目录结构、文档模板、命名规范、引用规范与维护约定，后续内容基于该骨架逐步补齐。

## 仓库约定

- 文档统一使用简体中文 Markdown。
- 目录统一使用英文命名。
- 文件统一使用中文命名。
- 结构化数据统一放入 `docs/04-Database/`。
- 模板统一放入 `templates/`。

## 主要入口

- `docs/`：知识库正文目录。
- `templates/`：统一文档模板。
- `CONTRIBUTING.md`：文档规范、引用规范、命名规范。
