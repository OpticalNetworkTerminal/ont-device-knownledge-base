## 记录模板

后续新增型号时，建议至少记录：

- 铭牌型号
- Web 显示型号
- 硬件版本
- 软件版本
- 运营商/地区
- 光接入类型
- `Web UI / OMCI / TR-069 / Telnet / SSH` 状态
- 已验证内容
- 待验证内容
