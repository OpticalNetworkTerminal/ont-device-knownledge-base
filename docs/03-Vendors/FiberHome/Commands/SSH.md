# SSH

本页先建立 `SSH` 操作索引。当前阶段仅保留“若设备已合法开放 SSH，建议如何记录和验证”的内容。

## 已验证内容

- 官方资料很少把 `SSH` 作为常规 ONT 管理面公开。
- `SSH` 是否存在，强依赖具体型号、固件和调试态。

## 待验证内容

- 各 `HG` 子型号是否存在可公开确认的 `SSH` 管理面
- `dropbear` 在不同固件中的存在范围

## 命令索引

### `ssh user@host`

| 字段 | 内容 |
| --- | --- |
| 功能 | 建立 SSH 会话 |
| 语法 | `ssh user@host` |
| 参数 | `user`、`host` |
| 返回值 | 登录成功后进入 shell；失败则返回认证或连接错误 |
| 示例 | `ssh admin@192.168.1.1` |
| 适用型号 | 已开放 SSH 的机型 |
| 风险等级 | 中 |
| 验证状态 | 通用用法，设备侧支持状态待验证 |
| 来源 | OpenSSH 通用 |

### `df -h`

| 字段 | 内容 |
| --- | --- |
| 功能 | 查看分区空间占用 |
| 语法 | `df -h` |
| 参数 | `-h` |
| 返回值 | 文件系统空间统计 |
| 示例 | `df -h` |
| 适用型号 | 已开放 SSH shell 的机型 |
| 风险等级 | 低 |
| 验证状态 | 通用命令，未实机验证 |
| 来源 | Linux/BusyBox 通用 |
