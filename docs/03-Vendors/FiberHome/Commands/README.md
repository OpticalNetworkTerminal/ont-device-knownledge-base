# Commands

本目录优先建设命令入口，避免再按 `Telnet`、`SSH`、`Debug` 拆成多个碎片页面。

## 命令索引

| 分类 | 页面 | 范围 |
| --- | --- | --- |
| `Shell` | [shell](./shell.md) | Telnet/SSH 进入后的巡检、串口、bootlog、启动参数 |

## 统一字段

每条命令统一使用以下字段：

- `功能`
- `语法`
- `参数`
- `返回值`
- `示例`
- `适用型号`
- `风险等级`
- `验证状态`
- `来源`

## 当前策略

- 先收录通用、只读、低风险命令
- 社区资料中的敏感命令只记录现象，不给出执行步骤
- 未实机验证的信息默认标记为 `社区资料` 或 `待验证`
