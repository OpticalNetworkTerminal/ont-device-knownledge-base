# 超级管理员与运营商限制

本页先作为问题索引页，统一管理“超管、隐藏菜单、运营商裁剪、地区差异”这类高争议主题。

## 已验证内容

- 官方资料通常只公开 `OMCI / Web UI / TR-069` 等常规管理面，不公开超级管理员维护方式。
- 公开研究表明部分 FiberHome 固件存在隐藏管理面和高风险接口，但不能据此泛化到全部型号。
