# FiberHome Research

本目录是 `FiberHome / 烽火 ONT` 的 Research Database。

用途：

- 收集
- 分类
- 建立索引
- 标记证据等级
- 保留未验证资料

限制：

- 本目录不是正式手册
- 本目录不是命令说明书
- 本目录不删除 `C/D` 级资料
- 本目录不把社区资料改写成官方结论

## Evidence

| 等级 | 定义 |
| --- | --- |
| `A` | 官方文档、官方源码、GPL 源码、RFC、ITU、Broadband Forum |
| `B` | GPL 分析、固件分析、源码分析、多来源一致 |
| `C` | 恩山、ChinaDSL、52pojie、OpenWrt Forum、多个社区一致 |
| `D` | 博客、个人经验、单一帖子、视频、转载页 |

## 当前收录原则

- 保留原始来源标题
- 保留原始链接
- 记录发布日期
- 记录 `Evidence`
- 记录适用型号
- 记录适用运营商
- 记录适用地区
- 记录最后收集时间

## 统一字段

所有研究条目尽量包含：

| 字段 | 说明 |
| --- | --- |
| `来源标题` | 原始页面标题或原始资源名 |
| `来源链接` | 原始 URL |
| `发布日期` | 页面标注日期；无则写 `未标注` |
| `Evidence` | `A/B/C/D` |
| `适用型号` | 页面直接涉及的型号 |
| `适用运营商` | 页面直接涉及的运营商 |
| `适用地区` | 页面直接涉及的地区 |
| `最后收集时间` | 当前仓库收录时间 |
