## Telnet

### 已验证内容

- `TEWA-708E`: 超管登录后访问 `/enableTelnet.html` 的路径存在。
- `TEWA-872G`: 可通过 `POST /setObjs` 写对象方式开启 Telnet。

### 待验证内容

- `telandftpcfg.cmd` 是否在全部 `TEWA-750/708/768/800/1000` 机型通用。
- 各型号 Telnet 默认用户是否统一为 `admin/admin`、`user/user`、或其它组合。
- Telnet 打开后是否仍受命令过滤。

## SSH

### 已验证内容

- `TEWA-1000E` 社区 GitHub Issue 中存在完整的 SSH 部署链路:
  - 修改 `/var/samba/smb.conf`
  - 通过 CIFS 映射根目录
  - 写入 `/opt/upt/apps/ssh/`
  - 运行 `start_ssh.sh`

### 待验证内容

- 非 `TEWA-1000E` 型号是否有相同目录结构。
- `sshd` 是否依赖特定 CPU 架构。
- 自启动脚本替换是否会影响诊断程序或运营商维护功能。

## Debug / 隐藏页面

### 已验证内容

- 可通过浏览器开发者工具在前端页面或请求中寻找 `sessionKey`。
- `usbbackup.cmd` 为已知可访问的隐藏页面入口之一。

### 社区资料

- `set2_sessionKey`、`set3_sessionKey` 常与恢复、Telnet/FTP 配置页面相关。
- 某些新固件中 `sessionKey` 不在 HTML 源码里，而在 `Network` 请求中出现。

## 配置恢复与升级

### 当前已知线索

- 配置可通过 U 盘或 FTP 导出。
- 某些设备可从 `/userconfig/cfg/db_user_cfg.xml` 抽取配置。
- 恢复出厂后通常需要重新记录或补回 `LOID`、宽带账号、业务配置。

### 待验证内容

- 天邑不同机型的“恢复出厂”是否清空 `LOID`、`SN`、`MAC`。
- 升级包格式、升级入口、签名校验策略。

## 超级管理员与运营商限制

### 当前已知线索

- 超管获取主要分三类:
  - 配置文件中提取 `TeleComAccount`
  - Telnet 后执行 `telecomadmin get`
  - 老型号执行 `CUAdmin get`
- 运营商限制主要体现为:
  - 页面隐藏
  - 参数写入受限
  - TR069/业务下发覆盖本地设置

### 待验证内容

- 超管密码是否每次业务下发后都会变化。
- 不同运营商定制固件对桥接、双模、Mesh 的限制项是否统一。

## 桥接 / Mesh / 双模

### 桥接

- 社区资料:
  - 大量帖子提到天邑设备可在超管界面改桥接。
  - 也有帖子显示业务下发后桥接设置可能被覆盖。
- 待验证:
  - 页面入口、业务模板、VLAN 绑定方式、IPTV 联动。

### Mesh

- 社区资料:
  - 有帖子提到 `hidden_version_switch.html` 或组网开关会影响副路由/组网模式显示。
- 待验证:
  - 天邑具体页面名、是否存在 `组网V2` 类开关、对主副设备角色的影响。

### 双模

- 社区资料:
  - 部分用户讨论 TEWA 设备在 GPON/EPON 等模式上的兼容与限制。
- 待验证:
  - 是否存在独立切换页面、切换后是否影响注册与业务下发。

## SN / MAC / LOID

### 当前原则

- 任何涉及 `SN`、`MAC`、`LOID` 改写、克隆、导回、重注册的步骤，一律先标记为高风险。
- 在缺少实机与运营商场景确认前，只保留索引与来源，不形成操作结论。

- 重新注册路径
