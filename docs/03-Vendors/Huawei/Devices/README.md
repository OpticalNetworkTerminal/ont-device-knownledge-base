# Devices

本页为华为光猫型号索引。它的目标不是把每台设备都写成单独文章，而是先建立“产品家族 + 资料密度 + 研究方向”的视图，方便后续持续补全。

## 阅读方式

- 想看“哪些型号资料最多”：先看 `重点机型`
- 想看“某机型适合去哪里找资料”：直接查表格的 `资料焦点`
- 想看“哪些型号只有研究线索”：看 `边界与低资料密度机型`

## 重点机型

当前资料密度最高、最适合作为整理锚点的机型有：

- `HG8245`：官方资料、配置解密、超管、FCC 线索都较丰富。
- `HG8321R`：GitHub 上的 Shell / Telnet / WAP 命令样本最多。
- `HN8145X6`：高版本运营商定制机的讨论最集中，涉及 `SN/MAC/LOID`、双模、TR069。
- `HS8145C5`：高版本社区改机资料较多，常与 Shell 补全、配置回传、包导入一起出现。
- `HG8012H`：串口、Bootloader、分区表和文件系统资料最完整。

## 边界与低资料密度机型

下面这些对象目前只适合作为资料入口保留，不宜下太强的正式结论：

- `AX3 / AX3 Pro`
  - 更接近华为路由器生态，而不是 ONT 主体。
- `HG8245A`、`HG8245Q`
  - 当前更多作为 FCC 或海外监管线索出现。
- `HS8545M`
  - 当前以社区固件资料线索为主，缺系统性公开整理。
