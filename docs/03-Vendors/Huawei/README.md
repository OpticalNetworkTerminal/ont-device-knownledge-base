# Huawei

本目录用于建设 `Huawei` 光猫参考手册，范围仅限华为 ONT/ONU 设备，不涉及其他厂商。

## 建设原则

- 采用“持续完善”模式，先建立索引与可追溯条目，再逐步补充细节。
- 社区帖子、论坛附件、逆向项目中的结论，默认标记为 `社区资料`，不得直接视为最终结论。
- 出现来源冲突时，保留多个观点，并在条目中注明差异。
- 只有完成实机确认后，相关条目才可升级为 `已实机验证`。

## 验证状态定义

| 状态 | 含义 |
| --- | --- |
| `已整理` | 已纳入知识库并完成结构化整理 |
| `官方资料` | 可从华为官方资料入口确认功能或产品存在，但未完成光猫实机映射 |
| `社区资料` | 主要来自论坛、博客、GitHub 实测或逆向记录 |
| `多源一致` | 两个及以上独立社区来源描述接近 |
| `待实机验证` | 尚未在真实设备上复核，不能作为最终结论 |
| `已实机验证` | 后续通过真实设备操作确认 |

## 已验证内容

这里的“已验证”仅表示“已完成文档层整理与来源归档”，不是“已实机验证”。

- 已建立华为目录结构与索引入口。
- 已建立第一版命令参考模板，统一字段为：`功能 / 参数 / 返回值 / 示例 / 适用型号 / 风险等级 / 验证状态 / 来源`。
- 已建立第一版型号索引，区分 GPON、Wi-Fi 一体机、桥接型与高版本机型。
- 已建立第一版操作索引，区分接入、配置、身份参数、恢复升级与协议管理。

## 待验证内容

- `descrypt` 在华为光猫上的具体命令名、参数差异与适用固件。
- `SSH/STelnet` 是否在民用 EchoLife 固件中默认可用，还是仅见于企业设备文档。
- `修改 MAC`、`修改 LOID`、`修改 SN` 在不同地区定制固件中的字段映射。
- `双模`、`Mesh`、`LED 全闪`、`恢复华为原厂界面` 等操作在不同型号上的成功条件。
- `TR069` 与 `OMCI` 参数修改后是否会被运营商再次下发覆盖。
