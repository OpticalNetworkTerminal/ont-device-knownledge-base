# Operations

本页只做“操作索引”，不写教程式步骤。每个主题仅记录入口、状态和后续补充方向。

## 接入方式索引

| 操作主题 | 说明 | 当前状态 | 主要来源 |
| --- | --- | --- | --- |
| `Telnet` | 社区资料中最常见的维护入口，常见账号为 `root/admin` 或 `root/adminHW` | `社区资料` `多源一致` `待实机验证` | 恩山、ChinaDSL、GitHub |
| `Serial` | 适用于 Telnet 关闭或 Web 受限场景，常见串口速率见社区逆向记录 | `社区资料` `待实机验证` | GitHub 串口逆向项目 |
| `SSH` | 华为官方文档能确认设备体系存在 Telnet/STelnet 管理概念，但是否适用于民用 ONT 需分型号确认 | `官方资料` `待实机验证` | Huawei Support |

## 配置文件与权限索引

| 操作主题 | 说明 | 当前状态 | 主要来源 |
| --- | --- | --- | --- |
| `读取 hw_ctree.xml` | 社区资料中最常见的配置导出对象 | `社区资料` `多源一致` `待实机验证` | 恩山、ChinaDSL、GitHub |
| `读取 hw_default_ctree.xml` | 常用于比对默认值、地区差异和恢复逻辑 | `社区资料` `待实机验证` | 恩山、ChinaDSL |
| `读取 hw_boardinfo` | 常用于设备标识、SN/MAC/模式信息修改 | `社区资料` `待实机验证` | ChinaDSL、恩山 |
| `AES/XML 加解密` | 社区普遍通过工具或 `aescrypt2` 处理配置文件 | `社区资料` `多源一致` `待实机验证` | GitHub、ChinaDSL |
| `超级管理员读取/新增` | 常围绕 `telecomadmin`、`UserLevel="0"` 与 `PassMode` 展开 | `社区资料` `多源一致` `待实机验证` | ChinaDSL、恩山 |

## 运营商限制与协议索引

| 操作主题 | 说明 | 当前状态 | 主要来源 |
| --- | --- | --- | --- |
| `TR069` | 常见于远程下发配置、恢复路由模式、重置超管密码等场景 | `社区资料` `多源一致` `待实机验证` | ChinaDSL、博客、官方 TR069 文档入口 |
| `OMCI` | 属于 ONT 与 OLT 管控链路，社区常将兼容性问题归于 OMCI 差异 | `官方资料` `社区资料` `待实机验证` | Huawei Support、GitHub |
| `运营商定制界面限制` | 如仅开放普通账号、隐藏桥接、锁定 SSID 或地区模板 | `社区资料` `多源一致` `待实机验证` | ChinaDSL、恩山 |
