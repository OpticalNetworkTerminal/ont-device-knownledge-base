## 使用原则

- 文本解释尽量简短，长说明回链到 `Commands`、`Platform` 或 `Research`
- 同一条命令、字段、型号不要在多个 Markdown 中各写一套
- 有争议时保留多条记录和 Evidence，不做静默覆盖

该目录用于收录中兴设备配置数据库、参数模型和持久化方式相关资料。
