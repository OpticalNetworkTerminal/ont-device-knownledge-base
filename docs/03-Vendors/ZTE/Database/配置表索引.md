# 配置表索引

本页整理 `sendcmd` / `sidbg` 语境下最常见的配置表、配置文件与关联动作。这里是索引，不承担长篇操作说明。

## 当前结论

公开资料稳定指向一种“表 + 行 + 字段”的配置数据库模型，但表结构、字段名、行号和持久化方式不保证跨型号一致。

## 高优先级表

| 表名 | 常见用途 | 示例 | Evidence |
| --- | --- | --- | --- |
| `TelnetCfg` | Telnet 开关、端口、账号、连接数 | `sendcmd 1 DB p TelnetCfg` | B/C |
| `DevAuthInfo` | Web 管理账户、密码、权限级别 | `sendcmd 1 DB set DevAuthInfo 0 Pass xxx` | B/C |
| `TelnetUser` | Telnet 用户名与密码 | `sidbg 1 DB set TelnetUser 0 Username root` | C |
| `MgtServer` | TR-069 / ACS 管理配置 | `sendcmd 1 DB p MgtServer` | C |
| `WANC` | WAN 连接使能与配置 | `sendcmd 1 DB p WANC` | C |
| `PortControl` | 端口开关或服务开放控制 | `sendcmd 1 DB p PortControl` | C |
| `DevInfo` | 设备基本信息 | `sendcmd 1 DB p DevInfo` | C |

## 高频动作

| 动作 | 示例 | Evidence |
| --- | --- | --- |
| 列表 | `sendcmd 1 DB all` | B/C |
| 打印表 | `sendcmd 1 DB p TelnetCfg` | B/C |
| 修改字段 | `sendcmd 1 DB set TelnetCfg 0 Lan_Enable 1` | B/C |
| 删除记录 | `sendcmd 1 DB delr <table> <row>` | C |
| 保存 | `sendcmd 1 DB save` | B/C |

## 配置文件线索

| 文件名 | 角色猜测 | Evidence |
