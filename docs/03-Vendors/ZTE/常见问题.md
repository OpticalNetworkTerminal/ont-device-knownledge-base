# 常见问题

## 为什么很多中兴资料彼此冲突？

因为不同型号、不同硬件代际、不同运营商定制版本差异都很大。社区资料只能先记为线索，不能直接当最终结论。

## 为什么这里没有直接给出所有超级密码？

因为公开资料大多来自社区，且不同运营商版本经常变化。本知识库目前只记录“来源、范围、验证状态”，不把未经验证的信息写成通用默认值。

## `sendcmd` 和 `sidbg` 是不是所有机型都有？

不能下这个结论。它们在公开资料里很常见，但并不代表所有 ZTE ONT 都开放、也不代表语法完全一致。

## 为什么 `SSH/FTP/TFTP` 页内容还很少？

因为这一轮优先做目录结构、索引和已验证内容。缺少稳定公开证据的主题先建档，后续等实机或更多一手资料再补充。
