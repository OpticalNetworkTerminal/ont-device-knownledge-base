# 恢复出厂

## 目标

把设备恢复到默认配置状态。

## Evidence

C

## 已知路径

- Web 管理界面恢复
- 配置数据库恢复相关命令
- 按键 / 串口 / 低层恢复

## 当前共识

- “恢复出厂”是稳定存在的维护目标
- 但“恢复出厂”不等于“重新刷完整固件”
- 是否保留 SN / MAC / LOID / 运营商参数，必须按设备记录

## 常见命令线索

```sh
sendcmd 1 DB rreset
sendcmd 1 DB reboot
```

## 风险

- 可能清空可写配置
- 可能导致认证参数丢失
- 某些版本恢复后会重新被运营商侧下发覆盖
