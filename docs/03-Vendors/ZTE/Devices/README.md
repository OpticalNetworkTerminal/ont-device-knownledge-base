# Devices

本目录采用“每个设备一个目录”的方式，避免把 `G7615`、`F7607`、`F7005` 等不同硬件/运营商版本混成一篇。

## 设备目录模板

每个设备目录后续至少包含：

- `README.md`：设备概览、版本、Evidence、适用命令
- `versions.md`：固件版本、主备版本、地区码、来源
- `notes.md`：只属于该设备的观察记录
