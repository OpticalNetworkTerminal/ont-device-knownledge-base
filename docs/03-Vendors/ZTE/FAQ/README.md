# FAQ

## 为什么 ZTE 目录要拆成这么多层

因为 `命令是什么`、`怎么做`、`设备差异`、`社区猜测` 本来就不是同一种知识。如果混在一起，后续增加 `G7615`、`F7607`、`F7005` 时会越来越难维护。

## 为什么很多内容被放进 Research 而不是直接进 Guides

因为这批主题虽然有价值，但当前更多是“线索集合”而不是“稳定操作路径”。先保留，再逐步升级，比直接删掉更适合长期维护。

## 为什么 sendcmd 要拆成命令页、数据库索引和研究页

因为 `sendcmd` 本身同时涉及命令语法、表结构和社区收集。把三者分层后，后续补充不会再把一篇文档越写越长。
