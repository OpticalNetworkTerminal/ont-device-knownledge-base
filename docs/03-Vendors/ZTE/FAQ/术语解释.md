# 术语解释

## ONT

光网络终端。本目录语境下通常指家庭侧光猫或集成网关。

## sendcmd

ZTE 社区资料中最常见的维护命令入口之一，常用于访问配置数据库和部分调试信息。

## sidbg

社区资料中常见的另一类调试 / 数据库访问入口，常与 `sendcmd` 对照出现。

## TelnetCfg

常见配置表名，通常与 Telnet 开关、账号、密码、连接数有关。

## DevAuthInfo

常见配置表名，通常与 Web 管理账号、密码和权限有关。

## MgtServer

常见管理配置表名，通常与 TR-069 / ACS 有关。

## WANC

常见 WAN 配置表名。

## LOID

光接入侧逻辑标识，常用于运营商认证。
