# 超级管理员

## 功能

整理中兴 ONT 中高权限 Web/Telnet 账户、提权方式和运营商定制差异。

## 当前结论

- 社区资料普遍存在“超级管理员/超密/工厂账号”概念
- 但不同运营商、不同机型差异极大

## 已验证内容

- `zte_factroymode.py` 默认尝试了多组运营商相关用户名/密码，说明该问题具有明显运营商定制属性。

## 社区资料

- `telecomadmin`
- `CMCCAdmin`
- `CUAdmin`
- `cqadmin`
- 通过 `DevAuthInfo` 或 `TelnetCfg` 修改账号口令

## 风险等级

高
