# 恢复出厂

## 功能

将设备恢复到默认配置状态。

## 当前结论

- 这是稳定存在的维护目标
- 但“恢复出厂”不等于“回到运营商出厂状态”

## 已验证内容

- 社区资料普遍把恢复操作与配置数据库保存、重启、Web 恢复页面分开讨论，说明它至少不是单一路径。

## 待验证

- 是否清除 LOID/SN/MAC
- 是否保留某些运营商定制参数
