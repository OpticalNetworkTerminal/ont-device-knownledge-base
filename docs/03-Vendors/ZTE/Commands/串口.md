# 串口

## Evidence

B

## 功能

串口用于观察启动日志、进入低层维护环境和执行恢复操作。

## 已验证内容

- FCC 对多款 ZTE ONT 公开了内部照片，这为定位 UART 焊点提供了一手材料基础。
- `zte_modem_tools` 公开实现了 `serial` 开关相关逻辑，说明部分社区研究对象存在与串口有关的网页/工厂模式控制路径。

## 风险等级

高

## 验证状态

- 串口作为低层维护方向存在：已验证
- 具体焊点、电平和波特率：待验证
