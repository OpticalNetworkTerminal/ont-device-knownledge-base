# Research

本目录是 ZTE 知识体系里最重要的缓冲层，用于保留论坛资料、GPL 分析、实验记录、猜测和待验证主题。这里的内容不会因为暂时无法实机验证而删除，但必须标记 Evidence。

## Evidence Level

| 等级 | 含义 |
| --- | --- |
| A | 官方文档、官方源码、GPL 源码、实机验证 |
| B | GPL 分析、多来源一致、源码分析 |
| C | 恩山、ChinaDSL、52pojie、GitHub 讨论等多个社区来源一致 |
| D | 单一论坛、博客、经验贴、未交叉验证记录 |
