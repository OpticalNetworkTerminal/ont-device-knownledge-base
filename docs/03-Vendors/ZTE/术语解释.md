# 术语解释

## ONT

光网络终端。本目录语境下通常指家庭侧光猫或集成网关。

## GPON ONT

FCC 与厂商资料中常见的设备类别名称，表示 GPON 光接入终端。

## sendcmd

社区公开资料中常见的 ZTE 维护命令入口，常用于访问配置数据库和调试信息。

## sidbg

社区公开资料中常见的另一类调试/数据库访问命令入口，常与 `sendcmd` 对照出现。

## TelnetCfg

社区资料中反复出现的配置表名，通常与 Telnet 开关、用户名、密码、连接数和权限有关。

## DevAuthInfo

社区资料中常见的认证表名，通常与 Web 管理账户、权限级别和密码有关。

## LOID

光接入侧逻辑标识，常用于运营商认证。不同运营商策略不同。

## TR-069

运营商远程管理协议。社区资料常将其与本地配置回写、远程覆盖联系起来讨论。
