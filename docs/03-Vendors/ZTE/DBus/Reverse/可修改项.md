# 可修改项

本页来自采集到的 `readwrite` Property。它们是“候选可修改项”，不是“已安全验证项”。

## 总览

| 分类 | 对象 | RW 字段 | 风险 |
| --- | --- | --- | --- |
| WiFi | `Config/WLAN/Devices/{1..8}` | `SSID/PWD/Enable/Channel/TransmitPower/...` | 中到高 |
| WPS | `Config/WLAN/Devices/{n}/WPS` | `Enable` | 中 |
| DHCP | `Config/DHCPServer` | `LocalIP/Submask/DHCPStartIP/DHCPEndIP/...` | 高 |
| LAN 口 | `Config/EthernetConfig/{1..4}` | `Enable/X_CU_Mode` | 中 |
| 客户端 | `Config/LANHosts/{1..19}` | `DevName/DevType/UsBandwidth/DsBandwidth/...` | 低到中 |
| QoS | `Transfer/TrafficQoSFlow/{1..8}` | `UpSpeed/DownSpeed/DSCPRemark` | 中 |
| Storage | `Storage/FTPServers/1`, `Storage/SambaServer` | `Enable/Anonymous/Port/FTPPath/UserName/Password` | 中到高 |
| Network | `Network/HTTPServer`, `Network/SpeedTestTry` | `Enable/UserName/Password/TestURL/...` | 高 |
| FTTR | `FTTR/Slave` | `AllowSlaveNum` | 中 |
| System/Framework | `com.cuc.ufw1`, `com.cuc.appframework1` | 日志级别、阈值等 | 中 |

## WiFi

对象：`/com/cuc/igd1/Config/WLAN/Devices/{1..8}`

| 字段 | 含义 | 建议 |
| --- | --- | --- |
| `SSID` | WiFi 名称 | 可测试，但会影响用户识别网络 |
| `PWD` | WiFi 密码 | 谨慎，可能导致终端掉线 |
| `Enable` | 开关 | 谨慎，可能关闭无线 |
| `EncryptionMode` | 加密方式 | 谨慎，错误值会导致无法连接 |
| `TransmitPower` | 发射功率 | 可测试低风险范围 |
| `Channel` | 信道 | 谨慎，可能触发无线重启 |
| `AutoChannelEnable` | 自动信道 | 相对可控 |
| `SSIDAdvertisementEnabled` | SSID 广播 | 可测试 |
| `FrequencyWidth` | 频宽 | 谨慎 |
| `Standard` | 制式 | 谨慎 |
| `IsGuest` | 访客网络标记 | 不建议修改，可能影响实例角色 |
| `X_CU_Mode` | 联通定制模式 | 待验证 |
| `Duration` | 持续时间 | 待验证 |
| `PortIsolation` | 客户端隔离 | 可测试但影响互访 |

## DHCP

对象：`/com/cuc/igd1/Config/DHCPServer`

| 字段 | 含义 | 建议 |
| --- | --- | --- |
| `DHCPServerEnable` | DHCP 开关 | 谨慎 |
| `LocalIP` | LAN 管理地址 | 高风险，可能断开管理连接 |
| `Submask` | 子网掩码 | 高风险 |
| `DHCPStartIP` | 地址池起始 | 中高 |
| `DHCPEndIP` | 地址池结束 | 中高 |
| `DHCPDuration` | 租期 | 中 |

## 客户端

对象：`/com/cuc/igd1/Config/LANHosts/{1..19}`

| 字段 | 含义 | 建议 |
| --- | --- | --- |
| `DevName` | 客户端显示名 | 推荐优先验证 |
| `DevType` | 客户端类型 | 推荐优先验证 |
| `UsBandwidth` | 上行限速 | 谨慎 |
| `DsBandwidth` | 下行限速 | 谨慎 |
| `UsGuaranteeBandwidth` | 上行保障带宽 | 待验证 |
| `DsGuaranteeBandwidth` | 下行保障带宽 | 待验证 |

## Storage

| 对象 | 字段 | 说明 |
| --- | --- | --- |
| `Storage/FTPServers/1` | `Enable`, `Anonymous`, `Port`, `FTPPath`, `UserName`, `Password` | FTP 服务配置 |
| `Storage/SambaServer` | `Enable`, `Anonymous` | Samba 服务开关与匿名访问 |
| `Storage/SambaServer/Accounts/1` | `UserName`, `Password` | Samba 账号 |

## QoS

对象：`Transfer/TrafficQoSFlow/{1..8}`

| 字段 | 含义 |
| --- | --- |
| `UpSpeed` | 上行速率限制或配置 |
| `DownSpeed` | 下行速率限制或配置 |
| `DSCPRemark` | DSCP 标记 |

## 建议优先验证顺序

1. `LANHosts/{n}.DevName`
2. `LANHosts/{n}.DevType`
3. `WLAN/Devices/{n}.SSIDAdvertisementEnabled`
4. `WLAN/Devices/{n}.TransmitPower`
5. `WLAN/Devices/{n}.SSID`
6. `DHCPServer.DHCPDuration`
7. `DHCPServer.LocalIP`

最后两项需要有串口、备用管理 IP 或恢复方案。
