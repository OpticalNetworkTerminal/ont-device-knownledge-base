# 分析结论

## 已确认

以下结论直接来自 DBus Explorer 导出数据：

1. 设备存在 `com.cuc.igd1` 核心业务 Service。
2. `com.cuc.igd1` 下采集到 127 个 object。
3. 设备业务对象广泛使用 `com.cuc.igd1.Properties`，不是标准 `org.freedesktop.DBus.Properties`。
4. 设备集合对象广泛使用 `com.cuc.igd1.ObjectManager`，不是标准 `org.freedesktop.DBus.ObjectManager`。
5. WiFi 配置对象为 `/com/cuc/igd1/Config/WLAN/Devices/{1..8}`。
6. DHCP 配置对象为 `/com/cuc/igd1/Config/DHCPServer`。
7. 客户端数据库对象为 `/com/cuc/igd1/Config/LANHosts/{1..19}`。
8. WAN 状态对象为 `/com/cuc/igd1/Info/Network/WANConnectionDb/{1,2}`。
9. PON 状态对象为 `/com/cuc/igd1/Info/PON`。
10. QoS flow 对象为 `/com/cuc/igd1/Transfer/TrafficQoSFlow/{1..8}`。
11. NAS 文件操作对象为 `/com/cuc/igd1/Storage/NAS`。
12. 系统命令对象为 `/com/cuc/igd1/Unicom/System`。
13. 采集到 309 个 RW Property，是配置修改候选入口。
14. 采集失败数量为 0。

## 高置信推断

以下结论来自对象路径、接口名和字段名，置信度高，但仍建议用 Web 后台抓包确认：

1. Web 后台 WiFi 设置页对应 `Config/WLAN/Devices/{n}`。
2. Web 后台 DHCP/LAN 设置页对应 `Config/DHCPServer`。
3. Web 后台终端列表对应 `Config/LANHosts`。
4. Web 后台 WAN 状态页对应 `Info/Network/WANConnectionDb`。
5. Web 后台 USB/NAS/Samba/FTP 页面对应 `Storage` 域。
6. Web 后台 QoS、加速、流控页面对应 `Transfer` 与 `Firewall` 域。

## 待验证

1. `Set` 与 `SetValues` 的完整 GVariant 参数格式。
2. Web 后台保存页面时使用 `Set` 还是 `SetValues`。
3. `Config/WLAN/Devices/{1..8}` 与 2.4G/5G/访客 SSID 的具体对应关系。
4. `X_CU_Mode`、`DSCPRemark`、`Duration` 等枚举字段的取值含义。
5. `LANHost.SetAttachSpeedup` 的参数和副作用。
6. `Unicom/System` 与 `ufw/appframework` 在升级流程中的职责边界。

## 逆向方向

推荐下一步：

1. 对 Web 后台关键页面做 DBus monitor。
2. 对 `com.cuc.igd1.Properties.SetValues` 做参数签名确认。
3. 从 `LANHosts.DevName` 开始做低风险写入验证。
4. 建立字段枚举值表，例如 WiFi 加密模式、连接类型、PON 状态。
5. 对危险方法只做 introspection，不做调用。
