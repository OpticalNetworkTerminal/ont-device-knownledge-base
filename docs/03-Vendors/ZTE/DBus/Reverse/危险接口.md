# 危险接口

本页自动关注方法名中的危险关键词：`Set`、`SetValues`、`Delete`、`Remove`、`Reset`、`Factory`、`Save`、`Apply`、`Commit`、`Upgrade`、`Reboot`、`Restart`、`Restore`。

## 风险分级

| 等级 | 含义 |
| --- | --- |
| 低 | 只读查询或无状态诊断 |
| 中 | 修改普通配置，可回滚 |
| 高 | 影响网络连接、访问控制、文件、账号 |
| 极高 | 重启、恢复、升级、删除全部对象、系统命令 |

## 极高风险

| Service/Object | Method | 风险 |
| --- | --- | --- |
| `com.cuc.igd1:/Unicom/System` | `Reboot` | 设备重启 |
| `com.cuc.igd1:/Unicom/System` | `Restore` | 恢复配置，可能清空设置 |
| `com.cuc.igd1:/Unicom/System` | `LocalRecovery` | 本地恢复流程，影响系统状态 |
| `com.cuc.igd1:/Unicom/System` | `InformUpgrade` | 升级通知/触发链路，待验证 |
| `com.cuc.appframework1:/com/cuc/appframework1` | `Upgrade` | 应用升级 |
| `com.cuc.appframework1:/com/cuc/appframework1` | `Restore` | 应用恢复 |
| `com.cuc.ufw1:/com/cuc/ufw1` | `Upgrade` | 固件框架升级 |
| `com.cuc.ufw1:/com/cuc/ufw1` | `Restore` | 固件框架恢复 |
| 任意 `com.cuc.igd1.ObjectManager` | `RemoveAllObjects` | 删除集合下所有对象 |

## 高风险

| 对象 | Method | 影响 |
| --- | --- | --- |
| `ObjectManager` 集合对象 | `DeleteObject` | 删除配置实例 |
| `Firewall/IPSet` | `AddIPSet`, `DeleteIPSet`, `DeleteIPSetEntry` | 影响防火墙规则 |
| `Storage/NAS` | `Remove`, `Move`, `Rename`, `Copy` | 影响 USB/NAS 文件 |
| `Unicom/PPPoE/2` | `SetPPPOEAccount`, `SetPPPOEAction` | 影响拨号账号或连接动作 |
| `Network/HTTPServer` | `Set/SetValues` | 可能影响 Web 管理入口 |
| `Config/DHCPServer` | `Set/SetValues` | 可能导致 LAN 管理地址变化 |

## 中风险

| 对象 | Method | 影响 |
| --- | --- | --- |
| `Config/WLAN/Devices/{n}` | `Set/SetValues` | 影响 WiFi 配置 |
| `Config/WLAN/Devices/{n}/WPS` | `Set/SetValues` | 影响 WPS |
| `Config/EthernetConfig/{n}` | `Set/SetValues` | 影响 LAN 口 |
| `Transfer/TrafficQoSFlow/{n}` | `Set/SetValues` | 影响 QoS |
| `Diagnostics/IPPing` | `StartIPPingDiagnostics` | 发起诊断 |
| `Diagnostics/TraceRoute` | `StartTraceRouteDiagnostics` | 发起诊断 |

## 相对低风险

| 对象 | Method | 说明 |
| --- | --- | --- |
| 业务对象 | `Get`, `GetAll` | 只读 |
| 集合对象 | `GetManagedObjects` | 只读集合 |
| DBus 标准 | `Introspect`, `Ping`, `GetMachineId` | 只读/探测 |

## 测试建议

不要在生产设备直接调用：

```text
Reboot
Restore
LocalRecovery
Upgrade
RemoveAllObjects
DeleteObject
DeleteIPSet
Remove
SetPPPOEAccount
```

可在可恢复环境中优先测试：

```text
GetAll
GetManagedObjects
LANHosts.DevName Set
```
