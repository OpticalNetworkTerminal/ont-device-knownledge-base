# 接口现状

## 当前判断

现有公开资料稳定证明的是：

- 存在 `sendcmd` / `sidbg` 这类配置访问入口
- 存在 XML 配置文件与配置表模型
- 可能存在私有 IPC 或管理总线

但以下结论目前不能直接下：

- 所有设备都使用标准 D-Bus
- `sendcmd` 就是 D-Bus 的直接命令行封装
- 对象、接口、方法、属性、信号可以统一抽象成同一套模型
