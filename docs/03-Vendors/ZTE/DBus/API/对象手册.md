# 对象手册

本文按功能域整理 DBus 对象。所有路径省略公共前缀 `/com/cuc/igd1/`，调用时需补全完整路径。

## WiFi 配置

### `Config/WLAN/Devices/{1..8}`

| 项 | 内容 |
| --- | --- |
| Service | `com.cuc.igd1` |
| Object Path | `/com/cuc/igd1/Config/WLAN/Devices/{1..8}` |
| Interface | `com.cuc.igd1.WLANConfiguration` |
| 作用 | 管理 8 个 WiFi/SSID 实例 |
| 权限 | 配置字段 RW，统计字段 RO |

RW Property：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `SSID` | `s` | WiFi 名称 |
| `PWD` | `s` | WiFi 密码 |
| `Enable` | `b` | WiFi 实例开关 |
| `EncryptionMode` | `y` | 加密模式 |
| `TransmitPower` | `u` | 发射功率 |
| `Channel` | `u` | 信道 |
| `AutoChannelEnable` | `b` | 自动信道 |
| `SSIDAdvertisementEnabled` | `b` | SSID 广播 |
| `FrequencyWidth` | `s` | 频宽 |
| `Standard` | `s` | 无线制式 |
| `IsGuest` | `b` | 是否访客网络 |
| `X_CU_Mode` | `y` | 联通定制模式字段 |
| `Duration` | `t` | 持续时间/定时相关 |
| `PortIsolation` | `b` | 客户端隔离 |

RO Property：

| 字段 | 含义 |
| --- | --- |
| `BSSID` | 无线接口 BSSID |
| `ChannelsInUse` | 当前使用/占用信道 |
| `RadioType` | 射频类型 |
| `Bind` | 绑定关系 |
| `RemainDuration` | 剩余时长 |
| `MaxSta`, `OnlineSta` | 最大/在线终端数 |
| `TotalBytesSent/Received` | 累计流量 |
| `TotalPacketsSent/Received` | 累计包数 |
| `Errors*`, `DiscardPackets*` | 错误包、丢弃包 |
| `IfName` | 系统接口名 |

调用示例：

```sh
gdbus call --system \
  --dest com.cuc.igd1 \
  --object-path /com/cuc/igd1/Config/WLAN/Devices/1 \
  --method com.cuc.igd1.Properties.GetAll \
  com.cuc.igd1.WLANConfiguration
```

典型用途：

- Web 后台“WiFi 设置”“访客 WiFi”“隐藏 SSID”“信道/功率设置”。
- 状态页显示在线无线终端数和无线流量。

相关对象：

- `Config/WLAN/Devices/{n}/WPS`
- `Config/WLAN/Timer`
- `Info/WiFi`
- `Config/LANHosts/{n}`

注意事项：

- 修改 `PWD` 会影响所有已连接终端。
- 修改 `Channel` 与 `AutoChannelEnable` 可能触发无线重启。
- `Devices/1..8` 的具体 2.4G/5G/访客对应关系需结合 `RadioType/IsGuest/SSID` 实测。

## DHCP 与 LAN

### `Config/DHCPServer`

| 项 | 内容 |
| --- | --- |
| Interface | `com.cuc.igd1.DHCPServer` |
| 作用 | LAN 网关和 DHCP 服务配置 |

RW Property：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `DHCPServerEnable` | `b` | DHCP 开关 |
| `LocalIP` | `s` | LAN 网关 IP |
| `Submask` | `s` | 子网掩码 |
| `DHCPStartIP` | `s` | 地址池起始 |
| `DHCPEndIP` | `s` | 地址池结束 |
| `DHCPDuration` | `u` | DHCP 租期 |

调用示例：

```sh
gdbus call --system \
  --dest com.cuc.igd1 \
  --object-path /com/cuc/igd1/Config/DHCPServer \
  --method com.cuc.igd1.Properties.GetAll \
  com.cuc.igd1.DHCPServer
```

注意事项：

- 修改 `LocalIP/Submask` 可能导致当前管理连接断开。
- 修改地址池需确认不会与静态地址冲突。

### `Config/EthernetConfig/{1..4}`

| Interface | 作用 |
| --- | --- |
| `com.cuc.igd1.EthernetConfig` | 物理 LAN 口配置与状态 |

RW 字段：

- `Enable`
- `X_CU_Mode`

RO 字段：

- `Bind`
- `BitRate`
- `MaxBitRate`
- `DuplexMode`
- `BytesSent/Received`
- `PacketsSent/Received`

典型用途：后台 LAN 口状态、端口开关、端口速率显示。

## 客户端数据库

### `Config/LANHosts`

| Interface | 作用 |
| --- | --- |
| `com.cuc.igd1.LANHostManager` | 客户端集合管理 |
| `com.cuc.igd1.ObjectManager` | 管理客户端子对象 |

方法：

- `GetOnlineDeviceList`
- `GetOnlineDevicesSnapShot`
- `GetLANHostPathbyMAC`
- `GetManagedObjects`

调用示例：

```sh
gdbus call --system \
  --dest com.cuc.igd1 \
  --object-path /com/cuc/igd1/Config/LANHosts \
  --method com.cuc.igd1.ObjectManager.GetManagedObjects
```

### `Config/LANHosts/{1..19}`

| Interface | 作用 |
| --- | --- |
| `com.cuc.igd1.LANHost` | 终端身份、连接、无线质量、速率、流量 |

RW 字段：

- `DevName`
- `DevType`
- `UsBandwidth`
- `DsBandwidth`
- `UsGuaranteeBandwidth`
- `DsGuaranteeBandwidth`

RO 字段类型：

- 身份：`MAC`, `HostName`, `Brand`, `OS`, `Model`
- 连接：`IP`, `ConnectionType`, `ConnectInterface`, `SSIDName`
- 无线质量：`RSSI`, `SNR`, `Noise`, `Channel`, `RadioType`
- 流量速率：`UpSpeed`, `DownSpeed`, `RxBytes`, `TxBytes`

特殊方法：

```text
SetAttachSpeedup(in s MAC, ...)
```

推测用于给指定终端设置加速或附加提速策略，需实测参数。

## WAN 与网络状态

### `Info/Network/WANConnectionDb`

| Interface | 作用 |
| --- | --- |
| `com.cuc.igd1.WANConnectManager` | WAN 连接集合管理 |

方法：

- `GetInternetConnIndex`
- `GetWANConnByName`
- `GetManagedObjects`

### `Info/Network/WANConnectionDb/{1,2}`

| Interface | 作用 |
| --- | --- |
| `com.cuc.igd1.WANConnectionInfo` | 单个 WAN 连接状态 |

RO 字段：

- 基本：`WANName`, `IfName`, `ServiceList`, `LanInterface`
- VLAN：`VLANMode`, `VLANID`, `VLAN8021P`, `MulticastVlan`
- IPv4：`IPAddress`, `SubnetMask`, `Gateway`, `DNSServers`
- IPv6：`IPv6IPAddress`, `IPv6Gateway`, `IPv6Prefix`, `IPv6DNSServers`
- 状态：`ConnectionStatus`, `ConnectionType`, `NATEnabled`, `UpTime`
- 统计：`RxBytes`, `TxBytes`, `RxPkts`, `TxPkts`

调用示例：

```sh
gdbus call --system \
  --dest com.cuc.igd1 \
  --object-path /com/cuc/igd1/Info/Network/WANConnectionDb/1 \
  --method com.cuc.igd1.Properties.GetAll \
  com.cuc.igd1.WANConnectionInfo
```
