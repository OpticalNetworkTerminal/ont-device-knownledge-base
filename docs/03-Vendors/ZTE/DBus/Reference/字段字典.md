# 字段字典

本字典解释采集中反复出现的 Property 名称。含义来自字段命名、对象路径和常见网关语义；未直接验证的枚举值需实测。

## 类型速查

| DBus 类型 | 常见含义 |
| --- | --- |
| `s` | string |
| `b` | boolean |
| `y` | byte / enum |
| `u` | uint32 |
| `t` | uint64 |
| `i` | int32 |
| `d` | double |
| `as` | string array |

| `RadioType` | 射频类型 |

| `IsGuest` | 是否访客网络 |

| `Duration` | 持续时间/定时相关 |

| `MaxSta` | 最大客户端数 |
| `OnlineSta` | 在线客户端数 |
