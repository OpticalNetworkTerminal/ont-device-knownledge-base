# 配置数据库生命周期

## 启动

启动脚本设置 `OVSDB_PATH=/userconfig/cfg`。`cspd` 作为 DB Server 初始化
共享内存数据库，`sendcmd` 作为 DB Client 通过 libdb API 访问视图。

## 加载路径

```text
dbcCfgFileDecry
  -> 检查 60-byte header magic/version
  -> version 3/4: AES-CBC 解密外层块
  -> 解开内层 CRC/deflate 容器
  -> inflate 得到 XML
  -> 初始化/更新 DB shared memory
```

已验证：AES 外层解密由 `cspd` 调用 `libhardcode.so` 的
`AESCBCDecry` 完成，不是由 `sendcmd` 直接读写 XML。

## 保存路径

```text
dbAPISave
  -> 内层 deflate 打包并计算 CRC
  -> 外层 AES-CBC 加密
  -> 写入 /userconfig/cfg/db_user_cfg.xml
```

保存流程位于 `cspd`，`libdb.so` 提供 DB API 入口和 shared memory 访问接口。
