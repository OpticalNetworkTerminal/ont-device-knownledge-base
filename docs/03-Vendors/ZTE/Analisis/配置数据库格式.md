# 配置数据库格式

ZTE 配置数据库文件虽然使用 `.xml` 后缀，但运行样本显示它是二进制容器。

已验证的版本 3/4 栈结构：

```text
60-byte outer header
12-byte AES block header
AES-256-CBC ciphertext
  60-byte inner header
  12-byte compressed block header
  zlib/deflate payload
    XML database text
```

外层头以 `01 02 03 04` 开始，版本字段位于偏移 `0x04`。样本中
`db_user_cfg.xml` 和 `db_backup_cfg.xml` 是版本 4，默认配置多为版本 3。

更细的字段说明见仓库根目录 `db_user_cfg.xml.format.md`。
