# 术语解释

## 简介

本文整理 LinuxRuntime 章节中的常见术语，帮助后续 Buildroot、OpenWrt、DBus、LXC 章节统一用词。

## 背景

如果不先固定 `procfs`、`sysfs`、`devtmpfs`、mount、namespace、cgroup、daemon、TTY、socket 这些词，后续章节很容易出现概念滑动。

## 基本概念

本表聚焦启动完成后的 Linux 运行机制，不重复解释编译和 ELF 基础。

## 工作原理

```mermaid
flowchart TD
    A[Kernel] --> B[Process/Thread]
    A --> C[VFS]
    C --> D[/proc /sys /dev]
    B --> E[Daemon / Shell / Session]
    A --> F[Namespace / Cgroup]
    B --> G[Socket / Signal / Environment]
```

## 设计目的

- 统一语言
- 降低后续章节重复解释成本

## 优缺点

优点：

- 便于建立整体脑图

缺点：

- 需要结合各主题文档一起看

## 典型应用

- 分析 Rootfs
- 读启动脚本
- 理解容器与 IPC

## 在 Buildroot 中的位置

Buildroot Rootfs 启动后看到的一切运行时对象，基本都能在本表中找到对应抽象。

## 在 OpenWrt 中的位置

OpenWrt 虽然用户态组织更偏网络设备，但底层术语体系并没有变化。

## 在光猫中的体现

光猫分析里最常见的误解，几乎都来自把这些术语混用。

## 实际案例

把“socket 是文件”“`/proc` 不是磁盘文件”“容器里的 `/proc` 是 API 文件系统视图”三件事放在一起理解，很多现场疑问会顺很多。

## 实践操作

```bash
ps
mount
find / -type s 2>/dev/null | head
ls /proc /sys /dev 2>/dev/null
```

怎么看：

- 把输出按“进程、挂载、伪文件系统、设备节点、socket”五类重新归纳
